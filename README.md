# iPhoneインフォ メルカリURL手動入力版

Gmailのメルカリ通知で「もっと見る」を押して開いたURLを手動入力し、ページ内の商品をiPhone 16シリーズの中古平均価格と比較して、おすすめ商品をインフォグラフィックへ反映するPWAです。

## 特徴

- Gmailの読取・検索・ラベル操作なし
- 外部有料APIなし
- Playwrightなし
- 定期トリガーなし
- 「もっと見る」で開いたメルカリURLを手動入力
- ボタンを押した時だけ入力URLと商品ページを取得
- 商品一覧URLと商品個別URLに対応
- 入力URLは `mercari.com` ドメインだけを許可

セットアップは `MANUAL_URL_GAS_SETUP.md` を参照してください。URL取得処理を更新するときは、同梱の `Code.gs` をApps Scriptへ貼り付け、必ずウェブアプリを「新バージョン」で再デプロイしてください。
