# iPhoneインフォ 固定条件・新着自動検索版

固定済みのメルカリ検索条件から、アプリを開くたびにiPhone 16シリーズの新着商品を取得し、中古平均価格と比較して、おすすめ商品をインフォグラフィックへ反映するPWAです。

## 特徴

- Gmailの読取・検索・ラベル操作なし
- 外部有料APIなし
- Playwrightなし
- 定期トリガーなし
- 固定メルカリ検索URLをGAS側で管理
- アプリ起動時に毎回新着検索
- 前回候補を消し、今回取得した候補だけを表示
- 手動の再検索にも対応
- メルカリがJavaScript表示だけを返した場合は動的ページ対応へ自動切り替え

動的ページ対応では、直接取得で商品が0件だった場合に限り、公開検索URLをJina Readerへ送って商品欄の表示を待ちます。GAS URL、`APP_TOKEN`、Gmail情報は送信しません。

セットアップは `MANUAL_URL_GAS_SETUP.md` を参照してください。URL取得処理を更新するときは、同梱の `Code.gs` をApps Scriptへ貼り付け、必ずウェブアプリを「新バージョン」で再デプロイしてください。
