# iPhone出品インフォグラフィック作成アプリ

Mercariの商品URLを貼り付けて、機種名・容量・色・状態・不具合・バッテリー・通信状態をレーダーチャート付きのXポスト用画像にまとめるPWAです。

## Androidスマホでの使い方（GitHub Pages経由）

1. GitHubで新しいリポジトリを作成（例: `mercari-iphone-infographic`）
2. このフォルダの5ファイル（index.html / manifest.json / sw.js / icon-192.png / icon-512.png）をリポジトリ直下にアップロード
   - スマホなら GitHub アプリ、または github.com をブラウザで開いて「Add file → Upload files」でOK
3. リポジトリの Settings → Pages で
   - Source: `Deploy from a branch`
   - Branch: `main` / `/(root)`
   を選択して Save
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセス可能に
5. Android Chromeでそのページを開き、メニューから「ホーム画面に追加」するとアプリのように起動できます

（`keiba-pwa` と同じ構成・同じ手順です）

## 使い方

1. ①にMercariの商品URLを貼って「ページ情報を取得」
2. ②で機種名・容量・色・状態・不具合・バッテリー%などを確認し、必要なら修正
3. ③のスライダーでレーダーチャートのスコアを微調整
4. ④「インフォグラフィック画像を作成」→ 画像をダウンロードしてXに投稿

## 注意点・制限事項

- ページ取得は無料の公開CORSプロキシ（allorigins.win）経由です。プロキシが落ちている場合や、Mercari側のページ構造変更、非公開/削除済み商品では取得に失敗します。その場合は②に手動入力してください。
- 自動抽出（機種名・容量・色・状態・キャリア・バッテリー%・不具合）はタイトルと説明文の正規表現による推測です。誤検出の可能性があるため、投稿前に必ず出品ページの実際の記載と照合してください。
- 商品データはサーバーに送信・保存されません。すべてブラウザ内（クライアントサイド）で完結します。
- 大量URLの自動連続取得・自動投稿など、Mercariの利用規約に抵触しうる自動化は想定していません（単発・手動貼り付けのみ）。
