# iPhoneインフォ Gmail通知取得版

メルカリで保存した検索条件の新着通知メールをGmailから取得し、iPhone 16シリーズの中古平均価格と比較して、おすすめ商品をインフォグラフィックへ反映するPWAです。

## 特徴

- 検索結果ページの自動巡回なし
- 外部有料APIなし
- Playwrightなし
- 定期トリガーなし
- 「新着通知メールを検索」ボタンを押した時だけGmailを確認
- 処理済みメールと商品IDの重複を自動管理
- メール内の直接URL、URLエンコード、追跡リンクに対応
- 商品ページ取得失敗時はメール本文情報へフォールバック

セットアップは `GMAIL_GAS_SETUP.md` を参照してください。
